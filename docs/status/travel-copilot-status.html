What isn't proven yet

  • Cloud access today. Register the simulator's App Check debug token (Firebase console → App Check → Manage debug tokens), then re-run the catch-up test to see a draft actually improve.
  • Airplane mode on a real iPhone. Every on-device result so far ran in the simulator on a Mac. The plan's day-1 check (does on-device AI work through Firebase AI Logic with no signal and App Check on?) still needs an Apple Intelligence iPhone. The whole pitch depends on it.

  • App Check outside debug. Only the debug provider is set up. A TestFlight build needs App Attest, or written steps for judges.
App map

How the app is put together

Screens never call AI directly. They go through AIService, which asks the routing policy where a task should run, sends it through Firebase AI Logic, and logs the result. Bookings and answers are stored on the phone in SwiftData.

Hybrid routing

How each AI request picks device or cloud

Every request has a kind. Survive is help during the trip, so it prefers the phone. Prepare is set-up work that needs the cloud. Catch-up improves earlier drafts on good Wi-Fi; it's designed in the policy but nothing uses it yet.

Blue

How a Blue chat answer is made

The on-device model never writes the answer. It only picks which booking and which field the question is about; the app shows that stored value. A keyword check stops small talk from getting a booking value.

  Chat->>AI: classify (Survive)

What we need to figure out

Story

Which story does the video tell?

The original plan was "offline translation that upgrades itself when you're back online". The app has grown into a trip copilot: bookings, step-by-step journey and Blue. Pick one 3-minute story and build the missing piece it needs.

Blue

What should Blue answer?

Today it answers booking facts, distances and translations only. Travelers will ask "where can I eat nearby?" or "is my train late?". Option: when online, send open questions to Gemini with a clear Cloud label; when offline, say what it can do instead.

Hybrid

Where do judges see device and cloud working together?

The catch-up pass is now built: draft on-device offline, improved in the cloud later, shown in the same chat bubble and the Log. It needs one working cloud run to film.

Cost

Device
